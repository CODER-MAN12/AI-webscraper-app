AI Web Scraper and Presentation Generator

An automated desktop tool built with Flutter and Python (FastAPI) that scrapes structured data from web pages using targeted identifiers (IDs), organizes the information into Excel spreadsheets, and automatically converts it into polished presentations.

Features:
- Targeted ID Scraping: Precision web scraper that extracts specific data fields using targeted HTML element IDs rather than generic scraping.
- Excel Data Organization: Automatically compiles harvested data into clean, structured Excel sheets for easy review and analysis.
- AI Presentation Generation: Leverages integrated AI models via OpenRouter to transform raw scraped content into structured, presentation-ready slides.
- Portable Windows Desktop App: Zero-install local architecture bundling a custom Python environment and a responsive Flutter user interface.

Project Structure:
- Backend folder: FastAPI Python backend and scraping engine
- Frontend folder: Flutter desktop interface
- launcher.bat: Startup script for seamless local execution

Getting Started:
1. Clone the repository: https://github.com/CODER-MAN12/AI-webscraper-app.git
2. Run the EXE file to start both the backend server and the frontend app at the same time.
3. Keep the exe file in the folder.
4. Keep the app running for atleast one minute before using it 
5. If your extraction tool prompts you about long file paths, you can safely skip those files as they are not required to run the app.
