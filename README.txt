# AI-Powered Webscraper App

An automated AI web scraping application built with a Python backend and a Flutter frontend.

## 🚀 Features
- FastAPI & LangChain AI scraping logic
- Cross-platform Flutter user interface
- Real-time data processing

## 🛠️ Project Structure
- `Backend/`: Python FastAPI app, UV package management, AI scraping pipelines.
- `Frontend/`: Flutter application.

## 📦 Setup & Run

### Backend
1. `cd Backend`
2. `uv sync`
3. Run `main.py`

### Frontend
1. `cd Frontend`
2. `flutter run`
